Speak the language

The 9 terms that unlock every conversation

🧠
Parameters (B)
The model's "brain cells," in billions. More = smarter & bigger. 7B, 70B…
🧩
Tokens
Words chopped into pieces. Models read and write in tokens, not letters.
📜
Context window
Short-term memory for one chat. Frontier models now hold ~1M tokens.
💾
Weights
The trained "knowledge" file you actually download to run a model.
🔓
Open vs closed
Open = you can run it yourself. Closed = API only (GPT, Claude, Gemini).
🗜️
Quantization
Compressing a model so it fits your machine. "Q4" is the everyday default.
📦
GGUF
The file format you download to run a model locally on a laptop or desktop.
⚡
Inference
A fancy word for "the model running" — i.e. actually answering you.
🤖
Agent / harness
Code wrapped around a model so it can take actions, not just talk.

The big unlock

Two ways to use AI: Chat vs. Agents

💬
Chat interface — you talk, it answers
ChatGPT · Claude · Open WebUI. Great for writing, Q&A, brainstorming, learning. You're the one taking every action.
🤖
Agent harness — it takes actions
OpenClaw · Hermes · Claude Code. Give it a goal; it plans, uses tools, and does the work — files, schedules, research, real tasks.

Cloud vs Local

When to use which

☁️ Cloud ChatGPT / Claude Pro, phone apps
  • ✓Easiest — nothing to install
  • ✓The most powerful, frontier models
  • ✓Works on every device, instantly
  • ✕Your data leaves your machine
  • ✕Monthly subscription · needs internet
🖥️ Local Ollama / Hugging Face on your box
  • ✓Private — data never leaves the building
  • ✓Free after the hardware · works offline
  • ✓Fully customizable & tinker-friendly
  • ✕Limited by your hardware
  • ✕More setup · you maintain it
Most of us use both — cloud for muscle, local for privacy & tinkering.
